# Changelog
## 0.5.0 - 2026-10-31
- Routed the low-current P3R1 carrier; added matched schematic, project-local libraries and connector/carrier BOM.
- Ran native KiCad 10.0.8: both ERCs, carrier DRC and schematic parity clean; exported Gerbers, separate plated/non-plated drills, PDFs, STEP and native PCB images.
- Added carrier-aligned enclosure mounts/lid/clamp, corrected tip shapes and compiled eight closed OpenSCAD meshes with recorded checks.
- Added reproducible power/divider/drive and wire-resistance calculations, current handover and fabrication instructions.
- Kept physical, supplier, handheld-integration and medical release work explicitly open.
